# Página Editor Fantasma

Publicar `https://adsliberty.com/editorfantasma` no projeto do site Liberty Agency, usando identidade própria, avatar fornecido e três vídeos reais do estúdio. Oferta: R$297 em pagamento único; checkout ainda indisponível, com botão “Compra em breve”. Não prometer tradução, leitura labial, renderização completa de 3 horas, suporte ou instaladores que ainda não foram homologados.

## Contrato funcional

| Ação | API / persistência | Autorização | Auditoria e teste |
|---|---|---|---|
| Ver demonstrações | arquivos estáticos MP4, sem banco | pública | reprodução em desktop e celular |
| Navegar pela página | âncoras HTML, sem banco | pública | links e teclado |
| Consultar oferta | conteúdo estático, sem banco | pública | preço e estado do botão |
| Comprar | checkout futuro, sem chamada atual | indisponível | botão desabilitado; testar link e entrega antes de habilitar |

## Entrega

Validar HTML, CSS, vídeos, build, Playwright e rota direta; publicar de checkout limpo, preservando o trabalho local pendente do site. Renomear o aplicativo e os instaladores em etapa separada, com teste de instalação em Mac e Windows antes de anunciá-los.
